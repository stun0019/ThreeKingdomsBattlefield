# 三國戰場

雙擊根目錄的 `index.html` 即可在電腦瀏覽器遊玩單機版。畫面依 1280 × 720 設計；瀏覽器視窗若不是 16:9，請自行調整視窗或使用全螢幕。放到 GitHub Pages 後，也可用網站網址開啟。

- `index.html`：唯一 HTML 入口，包含畫面與介面樣式。
- `game.js`：已打包的遊戲程式，讓瀏覽器從 `file://` 直接載入。
- `src/`：可編輯的原始碼，以及 `src/ui/brush.woff2` 字型資源。
- `vendor/`：重建遊戲程式所用的 Three.js 原始檔。
